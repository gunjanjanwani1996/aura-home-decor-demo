# Aura Home Decor storefront (demo)

Static demo storefront for the Agentforce Home Advisor case study. The chat bubble is Salesforce
Messaging for In-App and Web (Enhanced Chat), connected to the Home Advisor Agent, with Omni-Channel
escalation to a human rep.

Live: https://gunjanjanwani1996.github.io/aura-home-decor-demo/

This repo holds only the published page. The source of truth is `demo/index.html` in the private
project repository; copy it here and push to republish.
